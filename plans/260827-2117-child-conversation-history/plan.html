Failure 1 · the premise was wrong

The plan claimed “There is no LIST query anywhere. This is the real gap.” There is one, at src/app/api/chat/route.ts:130-140 — capped at 30, with a message count and no excerpt. Nothing ever calls it.

Effect: phase 1 became a rewrite, not a creation.

Failure 2 · the query would have returned nothing

The excerpt SQL used m.role = 'user'. The check constraint messages_role_ck permits only ('child','assistant','system'), so it matches zero rows — no error, just a null excerpt on every row, forever.

Effect: corrected to 'child', with a test that would catch the regression.

Verified along the way, and load-bearing for the design: src/lib/chat/child-transcript.ts is in the G1 allowlist (eslint-rules/no-direct-message-query.js:13). Reading messages.content from a route handler fails pnpm lint. That constraint forces the module placement rather than merely recommending it.

F4 · high · the finding that matters most

A crisis message would have become permanent sidebar furniture. pipeline.ts:201-202 stores a child’s message as status='completed' even when it triggered a critical flag, and the excerpt query selects exactly that row.

So a child whose first message was “I want to kill myself” would see that sentence rendered back at them in the sidebar, every session, forever. The plan never considered it.

Fix (D11): a conversation flagged medium or above returns no excerpt at all — suppressed in the module, not the component, so the text never reaches the browser. The row shows a neutral, time-based label, styled exactly like every other row: no badge, no colour. A child should not be shown a marker on their own difficult moment.

F1 · high · the plan activates a dormant bug

schema.ts:138 promises the conversation’s age band is “Pinned at creation so a mid-conversation band change starts a new one.” Nothing implements that. route.ts:49 always uses the child’s current band for the guardrail.

Invisible today, because a conversation cannot outlive its page session. Phase 2 is what makes conversations persistent, so phase 2 is what activates it — and the bands genuinely differ: inap.sexual.topic.young is medium for under-12s where .older is low.

Fix (D12): on send, a band mismatch forks a new conversation. Reads are never gated by band — a birthday must not make a child’s history unreachable.
